# Data Science & Visualization Lab – 1

## Objectives

* Create and set up a Kaggle account.
* Create a Kaggle Notebook.
* Add the Titanic dataset.
* Load the dataset using Pandas.
* Perform basic data exploration.

## Topics Covered

* Importing libraries
* Reading CSV files (`pd.read_csv()`)
* Viewing data (`head()`, `tail()`)
* Dataset information (`info()`)
* Statistical summary (`describe()`)
* Checking missing values (`isnull().count()`)

## Dataset

* Titanic Dataset (Kaggle)

## Technologies Used

* Python
* Pandas
* Kaggle Notebooks
