# Python & Pandas File Handling Practicals

## 📌 Overview
This repository contains Google Colab practical exercises focused on handling different file formats using Python and Pandas. It covers CSV processing, missing values, JSON operations, HTML tables, and processing large CSV files in chunks.

## 🎯 Objectives
- Read and write CSV files using Pandas.
- Load CSV files without headers and assign custom column names.
- Set a column as the DataFrame index.
- Handle missing values using `NaN`.
- Export and import JSON data.
- Read HTML tables into Pandas DataFrames.
- Process large datasets efficiently using chunks.
- Calculate grouped averages across multiple chunks.

## 🛠️ Technologies Used
- **Python**
- **Pandas**
- **JSON** (`json` module)
- **Google Colab**

## 📚 Practicals Covered

### 1. CSV Without Headers
- Create a CSV file containing five columns without column headers.
- Load it using custom column names.
- Set the first column as the index using `index_col=0`.

**Key concepts:** `header=None`, `names`, `index_col`

### 2. CSV with Custom Delimiter and Missing Values
- Create a CSV file using a semicolon (`;`) as the delimiter.
- Convert `-999` values into `NaN` while reading the file.

**Key concepts:** `sep`, `na_values`

### 3. DataFrame to JSON and Back
- Export a DataFrame to JSON using `orient="records"`.
- Read the JSON file back into a DataFrame.
- Check whether both DataFrames are equal using `.equals()`.

**Key concepts:** `to_json()`, `read_json()`, `.equals()`

### 4. Reading HTML Tables
- Create a simple HTML table manually.
- Load the table into a DataFrame using `pd.read_html()`.

**Key concepts:** HTML table tags, `pd.read_html()`

### 5. Processing Large CSV Files in Chunks
- Read the Titanic dataset in batches of 2,000 rows.
- Group passengers by `Pclass`.
- Calculate the mean age for each passenger class across all chunks.

**Key concepts:** `chunksize`, `groupby()`, `agg()`, sum, count, and mean calculation.

**Dataset required:** `Titanic-Dataset.csv`

### 6. JSON Basics
- Convert JSON text into a Python object using `json.loads()`.
- Access nested data and retrieve the second item's name.
- Count the items in a list.
- Understand JSON `null` and its Python equivalent, `None`.
- Convert the Python object back to formatted JSON using `json.dumps()`.

**Key concepts:** `json.loads()`, `json.dumps()`, dictionary access, list indexing, `len()`, and `type()`.

### 7. JSON to DataFrame
- Convert the JSON `items` list into a DataFrame.
- Add a `total` column calculated as `price × qty`.
- Calculate the grand total.
- Find the item with the highest total.

**Key concepts:** `pd.DataFrame()`, column operations, `.sum()`, `.idxmax()`, and `.loc[]`.
